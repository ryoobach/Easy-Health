## Implemented HbA1c model

1. Auto-classify actual glucose measurements into eight daily slots using the saved wake, meal, and bedtime schedule.
2. Prefer actual readings. Fill missing slots from actual same-slot history over the previous 1, 2, or 3 weeks. Use personal meal pre/post delta where paired actual readings support it. Estimated values are never reused as historical evidence.
3. Apply a 30-day exponential half-life to the 720 daily slot representatives; the latest 30 days receive more than half of the total 90-day weight.
4. Convert the weighted mean glucose to estimated HbA1c using ADAG: `(mean glucose + 46.7) / 28.7`.
5. Record tab and all report periods call the same shared calculation function.

## Changes in 1.48

- Calendar short tap selects a date and displays that date's hospital appointments, health diaries, and notes without opening the editor.
- Calendar long press opens the unified entry editor.
- Unified entry editor body field reduced from four-to-seven lines to two-to-four lines.
- Editor synchronizes its initially selected category with the save handler, preventing an untouched initial tab from saving under a stale category.
- Long-press editing explicitly synchronizes the edited record category and clears the opposite edit target.
- Report HbA1c moved below the glucose graph and glucose summary.
- Report HbA1c uses the same `calculateTimeWeightedGlucoseEstimate` function as the Record tab: one recent-three-month estimate for 1 week, four weekly estimates for 1 month, three monthly estimates for 3 months, and rolling three-month estimates for All.

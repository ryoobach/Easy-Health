- Unified schedule-entry editor body field is reduced to 2–4 lines.
- Initial entry category is synchronized with the save handler.
- Existing appointment and diary/note records can be opened for editing.
- Each appointment/diary/note is rendered as an independent card in the selected day's timeline.

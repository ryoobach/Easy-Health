## Changes included

- Added a common 90-calendar-day HbA1c data builder with eight timestamped daily slots (720 slots per estimate).
- Actual glucose readings take precedence when assigned to the nearest configured slot.
- Missing slots use actual same-slot readings from the preceding 1 week, then 2 weeks, then 3 weeks; estimated values are not reused as historical evidence.
- Missing bedtime values can be bridged from actual dinner-post and next-morning fasting values when same-slot history is unavailable.
- Retained the 1.48 time-weighted averaging approach and ADAG conversion formula `(averageMgDl + 46.7) / 28.7`; the generated daily sequence allows up to 12-hour intervals to include the overnight bedtime-to-fasting span.
- Record and report tabs use the same engine and the last actual glucose date as their reference date.
- HbA1c report rows show the end date only, followed by average glucose, slot count, and HbA1c.
- Added tests for 720 slots, same-slot historical estimation, and actual-reading precedence.
- Updated `BUILD_GUIDELINES.md` so only successful builds consume version numbers; failed attempts must be fixed and retried using the same version.

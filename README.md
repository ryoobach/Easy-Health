# Easy Health

Android health log app.

## First version
- Manual blood glucose entry as the default workflow
- Unified glucose history sorted by measurement timestamp
- Local persistence on the device
- Automatic import button placeholder for future Bluetooth integrations

## Developer information
- Development: Ryoo Jaesang & 최피디
- AI development collaboration: ChatGPT (OpenAI)

Bluetooth integrations for Contour Plus ONE, CareSens Dual and Omron blood pressure monitors are planned and are not implemented in this initial build.
